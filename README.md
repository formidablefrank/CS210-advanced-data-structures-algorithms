# Advanced Data Structures and Algorithms

## Overview

I compiled this collection of coursework on advanced data structures and algorithms from my graduate studies in Computer Science. The repository contains comprehensive problem sets and analyses that demonstrate my proficiency in algorithm design, complexity analysis, and computational problem-solving.

## Technical Skills and Learning Objectives

Through this coursework, I developed expertise in:

- **Algorithm Design & Analysis**: Designing efficient algorithms and analyzing their time and space complexity using recurrence relations and asymptotic notation
- **Sorting & Merging**: Implementing advanced sorting techniques including multi-way merge sort with empirical performance comparison
- **Recurrence Relations**: Solving complex recurrence relations using algebraic methods, matrix exponentiation, and generating functions
- **Graph Algorithms**: Understanding network flow problems, maximum flow algorithms, and flow-based optimization
- **Mathematical Foundations**: Applying mathematical reasoning to prove algorithm correctness and derive complexity bounds

## Coding Exercises and Problem Sets

The repository includes two comprehensive problem sets:

**Problem Set 1**: Focuses on merge sort variations and recurrence relation analysis
- Implement merge sort without sentinel values
- Design three-way merge sort and compare performance empirically with standard two-way merge sort
- Analyze the number of comparisons in multi-way merge operations and derive closed-form complexity expressions
- Solve linear and non-linear recurrence relations

**Problem Set 2**: Covers advanced algorithm design techniques
- Network flow problems and maximum flow algorithms
- Classification problems using local search methods
- Flow-based optimization and computational complexity analysis

Each problem includes theoretical analysis, algorithm implementation details, complexity proofs, and empirical validation where applicable.

## Software Stack

- LaTeX (document preparation)
- Python (algorithm implementation and empirical analysis)

## Usage

To review the coursework:

1. Clone the repository
2. Open the problem set PDF files in `Probset1/` and `Probset2/` directories
3. Review the LaTeX source files (`ps1.tex`, `document.tex`) for implementation details and mathematical analysis
4. Examine the empirical results and performance comparisons included in the problem solutions
